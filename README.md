# dot_files

Personal configuration for Vim, Ghostty, and tmux.

## Files

- `vim/vimrc` -> `~/.vimrc`
- `ghostty/config` -> `~/.config/ghostty/config`
- `tmux/tmux.conf` -> `~/.tmux.conf`

Plugin managers install their own files outside this repository. Vim plugins
live under `~/.vim/plugged`, and tmux plugins live under `~/.tmux/plugins`.
